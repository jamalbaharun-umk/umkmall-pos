## Defects found and fixed

| # | Defect | Fix |
|---|---|---|
| D1 | Owners were signed out every 15 minutes: pos-web refreshes after the token lapses, but `/auth/refresh` sat behind the guard that refuses expired tokens and the cookie died with the token. The UMKMall-outage path was unreachable. | `6bb8972` refresh accepts an owner token expired ≤ 7 days, still gated by UMKMall liveness; owner cookie lives that window (e2e + revert-red) |
| D2 | PIN screen had no way back to the owner sign-in. | `6bb8972` link "Masuk sebagai pemilik toko" |
| D3 | Product list and view crashed for a cashier (cost price now hidden by pos-api, page read `costPrice.toLocaleString`). | `a4ebe4d` cost/profit columns and cards omitted when absent |
| D4 | Image picker accepted any file; a non-image or > 2 MB file failed only after saving. | `a4ebe4d` `splitImages` refuses at pick time with the field message (unit test) |
| D5 | `/catalog/products/baru` and `/ubah` showed the form to an actor without `catalog.manage`. | `a4ebe4d` no-permission state |
| D6 | PIN: the hardware keyboard kept typing digits while locked out (keypad buttons were disabled, keys were not). | `a4ebe4d` `press()` ignores input while busy/locked |
| D7 | After saving a form the next page stayed scrolled down (reset ran before the new page rendered). | `a4ebe4d` reset on the resolved location |
| D8 | A 403 page offered a useless "Coba lagi". | `a4ebe4d` no-permission state without retry |
| D9 | With pos-api stopped, pages showed the runtime's English "fetch failed" (reported by u5's sweep). | this commit: `api()` turns a connection failure into "Tidak bisa terhubung ke server kasir. Periksa koneksi lalu coba lagi." |
| D10 | Product form silently cleaned numbers: stock "-2" saved 2, price "1,5" became 15 (reported by ui-parity-b's sweep). | this commit: raw text validated (`check.wholeNumber`): "Stok awal tidak boleh negatif", "Harga modal harus bilangan bulat" (unit test) |

## OPEN

- **Store settings screen does not exist** (Lakasir General Setting: store name, currency…). No `/pengaturan` route is
  on main; the shell shows "Toko kamu". Recommendation: a small settings unit storing the store name (+ receipt
  header) on `pos.tenants`, owned by whoever takes Pengaturan; the nav line is already in `nav.ts`.
- **Category and role names are unique case-sensitively** ("Kasir" vs "kasir" both allowed); staff names are
  case-insensitive. Recommendation: one migration replacing the unique indexes with `lower(name)` ones (and adding the
  staff partial unique index that replaces today's read-then-write check).
- **Shell disappears during a UMKMall outage** (the page shows the message without the navigation, because the shell's
  "who am I" call fails too). Low; recommendation: keep the last known actor in the root loader and show a banner.

## Not exercised

The PIN countdown ticking in a visible tab (the browser pane was hidden, so timers were throttled; the server-side
lock and the 30 s → 60 s escalation were verified). A real UMKMall (the stub stands in for liveness only; the handoff
itself is covered by `auth.e2e-spec.ts`).
